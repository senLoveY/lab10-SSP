# ССП · Лабораторная работа № 10

## Вариант 1. Оценка риска кредитного заёмщика

Цель работы — обучить бинарный классификатор на C# с ML.NET. По характеристикам клиента и кредита модель оценивает вероятность возврата.

## Запуск

Откройте `Lab10.sln` в Visual Studio с поддержкой .NET 10 и запустите проект `CreditRisk` через Ctrl+F5. NuGet восстановит пакет `Microsoft.ML` версии 5.0.0. При сборке `data.csv` копируется в папку приложения.

На macOS или из терминала Visual Studio:

```sh
dotnet run --project CreditRisk
```

## Данные

В `CreditRisk/data.csv` сохранены все 32 581 записи из набора, имитирующего данные кредитного бюро. По выбранному для работы подходу используется готовый полный набор Kaggle, хотя методичка предусматривает 30–50 самостоятельно заполненных записей. [Credit Risk Dataset, Lao Tse, CC0](https://www.kaggle.com/datasets/laotse/credit-risk-dataset)

| Поле CSV | Тип в C# | Диапазон и преобразование |
| --- | --- | --- |
| `Age` | `float` | 20–144 года, исходное поле `person_age` |
| `Income` | `float` | 333,33–500 000 у. е. в месяц, `person_income` делится на 12 с округлением до двух знаков |
| `EmploymentYears` | `float` | 0–123 года, `person_emp_length`. 895 пропусков записаны как `NaN` |
| `CreditHistory` | `float` | 0 или 1. `cb_person_default_on_file`: `Y` → 1, `N` → 0. Поле отражает прошлый дефолт |
| `DebtToIncomeRatio` | `float` | 0–0,83. `loan_percent_income` — отношение суммы кредита к годовому доходу |
| `Target` | `bool` | `1` — возврат, `0` — дефолт. Исходная метка `loan_status` инвертируется |

## Обучение и проверка

В [Program.cs](CreditRisk/Program.cs) данные загружаются методом `LoadFromTextFile`. Конвейер заменяет пропуски стажа средним, объединяет пять признаков в вектор методом `Concatenate`, нормализует их методом `NormalizeMinMax` и обучает логистическую регрессию методом `SdcaLogisticRegression`.

Для оценки используется случайное разделение с `seed: 42`. Параметры обработки и классификатора вычисляются на 26 026 обучающих записях. На 6 555 тестовых записях доля верных ответов составила **80,6%**. Для прогнозов конвейер отдельно обучается на всех 32 581 записях.

Для дальнейшей оценки стоит сравнить модель с прогнозом по самому частому классу, измерить полноту обнаружения дефолтов и проверить влияние аномальных значений, таких как возраст 144 года и стаж 123 года.
